# Introduction

This is the first paragraph after a heading, so it carries no indent. Every paragraph that follows another is indented by 1.5em—the print equivalent of the web’s 3ch—and set justified with automatic hyphenation.

Headings are set in Alegreya Small Caps with a hairline rule beneath. Folios sit centred at the foot in oldstyle figures; the cover, the epigraph, the colophon and any blank pages carry none.

Use real typographic quotes—“like these”—and real dashes, because crown does no smart-quote conversion. Emphasis is *italic*; strong is **bold**; a name in small caps is <span class="canonical-name">Romello Goodman</span>; an acronym is <abbr>PDF</abbr>.
